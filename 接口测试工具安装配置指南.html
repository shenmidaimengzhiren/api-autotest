接口测试工具：下载安装与配置指南

Windows 环境 · 全部免费 · 按顺序装即可（前 4 个是主力，第 5-6 个是阶段三用）

建议安装顺序：Apifox（发请求）→ Fiddler Classic 或 Reqable（抓包）→ Python（写自动化）→ JMeter（性能）。

1Apifox（接口调试与测试主力）

下载：https://apifox.com/download ｜ 选 Windows 64 位 .exe

  1. 打开官网 → 点「免费下载」→ 选 Windows → 下载 Apifox-windows-x64.exe
  2. 双击安装（可改安装路径，建议不放 C 盘根目录），一路「下一步」
  3. 首次打开用手机号或微信扫码注册登录（免费版不限人数、项目数、接口数）
  4. 点「新建项目」→ 建一个叫「接口测试练习」的项目
  5. 项目内「新建接口」→ 填一个练习地址测试连通性：https://httpbin.org/get，点「发送」，返回 200 即成功
  6. 把常用环境配好：右上角「环境管理」→ 新建开发环境，把域名设为变量（如 {{baseUrl}} = https://httpbin.org），后续接口都用变量拼接
练习断言：在接口的「后置操作」里加断言，比如 json.data.url 包含 httpbin，这就相当于 Postman 的 Tests 脚本。

2Fiddler Classic（抓包，Windows 免费）

下载：https://www.telerik.com/download/fiddler ｜ 仅 Windows，仅个人非商业免费

  1. 打开页面 → 下拉找到下载表单 → 国家选 China、填邮箱、勾选「I confirm...」确认非商业用途 → 点 Download
  2. 下载得到 FiddlerSetup.exe，双击安装，一路下一步
  3. 关键一步：打开 Fiddler → 菜单 Tools → Options → HTTPS → 勾选 Capture HTTPS CONNECTs 和 Decrypt HTTPS traffic → 弹窗选 Yes 安装根证书
  4. 同一窗口点 Actions → Trust Root Certificate，全部选 Yes（不装证书只能看 https 的域名，看不到内容）
  5. 打开浏览器随便访问一个网站，左侧会话列表出现请求，点开可看请求头、响应体，即配置成功
常见坑：① 装完还是显示 tunnel to ... 说明证书没装好，重做第 3-4 步；② 浏览器用 Chrome/Edge 时若开了代理插件（如 SwitchyOmega），需关闭；③ 抓手机包需手机与电脑同 WiFi，手机 WiFi 设置里代理指向电脑 IP + 8888 端口，再用手机浏览器访问 http://电脑IP:8888 下载安装证书。

3Reqable（抓包，国产现代界面，可选替代 Fiddler）

下载：https://reqable.com/zh-CN/download ｜ Windows 7+，免费版够学习用

  1. 打开下载页 → Windows x86_64 → 选 exe（安装版，建议） 或 zip（免安装）
  2. 双击安装，首次打开会有引导，提示安装根证书时点「是 / 信任」（一键完成，比 Fiddler 简单）
  3. 点左上角「启动」开始抓包，浏览器访问网页即可看到流量
  4. 想抓手机：点「远程设备」按提示扫码 / 配置代理，App 内会给出完整步骤
Fiddler 和 Reqable 二选一即可。想跟教程就装 Fiddler（教程多），想要省心的中文界面就装 Reqable。

4Python（自动化基础，阶段三用）

下载：https://www.python.org/downloads/ ｜ 国内慢可用华为镜像 https://mirrors.huaweicloud.com/python/

  1. 下载 python-3.11.x-amd64.exe（3.9–3.12 都行，别装最新的 3.13+，部分库还没适配）
  2. 安装界面务必勾选最下方的「Add python.exe to PATH」，再点 Install Now
  3. 装完按 Win+R 输入 cmd，执行 python --version，能显示版本号即成功
  4. 装测试常用库（先配国内源加速）：
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip install requests pytest allure-pytest
常见坑：提示「python 不是内部或外部命令」= 没勾 PATH，重新运行安装包选 Modify 补勾，或手动加环境变量。

5JMeter（性能测试 / 接口压测，免费开源）

下载：https://jmeter.apache.org/download_jmeter.cgi ｜ 需要先装 Java（JDK 8 或 11+）

  1. 先装 JDK：搜索「Adoptium Temurin JDK 17」下载安装（免费开源版 Java）
  2. 到 JMeter 官网下载 Binaries 的 .zip 包（不要下源码包）
  3. 解压到不含中文和空格的路径，如 D:\tools\apache-jmeter-5.6
  4. 进 bin 目录双击 jmeter.bat 启动（会同时弹一个黑色命令行窗口，属正常，别关）
  5. 界面语言切中文：Options → Choose Language → 中文（简体）
常见坑：启动闪退多半是 Java 没装好或版本不对，命令行执行 java -version 确认；路径含中文会导致各种诡异报错。

练手用的免费接口（装完立刻就能测）

地址用途
https://httpbin.org/get最基础的 GET，返回你的请求头信息
https://httpbin.org/post练 POST 传 JSON / 表单
https://httpbin.org/status/404练状态码断言
https://httpbin.org/delay/3练超时设置
https://jsonplaceholder.typicode.com/posts练增删改查全套（有真实假数据）
https://petstore.swagger.io带完整文档的示例项目，练读文档写用例

验证是否装好（5 分钟自检）

  1. Apifox 能对 https://httpbin.org/get 发出请求并返回 200
  2. Fiddler / Reqable 启动后，浏览器访问任意网页能在列表里看到 https 请求的明文内容（不是 tunnel）
  3. 命令行 python --version 有输出，pip list 能看到 pytest 和 requests
  4. JMeter 能打开图形界面（暂时不用会，能启动就行）
