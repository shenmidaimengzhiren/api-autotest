软件测试 3 个月学习计划

目标：零基础 → 具备初级功能/接口测试工程师的求职能力。按每天 2–3 小时安排，可根据进度 ±1 周弹性调整。

执行原则：① 跟住一套课程，不要来回换；② 每学一个知识点当天动手操作一遍；③ 每周日晚花 30 分钟回顾本周内容并写学习笔记；④ 卡住超过 1 小时就去 CSDN / TesterHome 搜，不要死磕。

第 1–3 周阶段一：测试基础理论

目标：建立测试思维，能独立为一款 App / 网站写完整测试用例

  • 第 1 周：软件测试概念、测试流程（需求评审→计划→用例→执行→回归→报告）、黑盒/白盒、测试分级（单元/集成/系统/验收）
  • 第 2 周：用例设计方法 —— 等价类划分、边界值分析、判定表、场景法（重点，逐个练透）
  • 第 3 周：Bug 生命周期、缺陷报告写法；安装禅道，练习提交和管理缺陷；为一个真实产品（如微信发红包、12306 购票）完整写一份测试用例
资源：B 站「戴师兄」用例设计实战 + 任一套 2024 年后的零基础入门课；《软件测试的艺术》睡前翻阅

✓ 检验：能不看教程，独立写出一份 50+ 条用例的 Excel/XMind 测试用例文档

第 4–6 周阶段二：SQL + Linux + 接口测试

目标：掌握初级测试岗的三大硬性门槛技能

  • 第 4 周：MySQL —— 增删改查、where/order by/group by、多表连接（join）、常用聚合函数；每天在菜鸟教程在线练习 + 本地装 Navicat 实操
  • 第 5 周：Linux 基础 —— 文件操作、grep/tail 查日志、ps/top 查进程、vim 基本编辑；装一个虚拟机或用云服务器练
  • 第 6 周：HTTP 协议基础 + Postman 接口测试（请求方法、状态码、Cookie/Token）；Fiddler 抓包，学会定位问题是前端还是后端
资源：菜鸟教程（SQL/Linux 手册）；B 站「白阁测试」Postman 教程；《SQL 必知必会》

✓ 检验：给定一个开放接口（如聚合数据免费 API），能用 Postman 完成接口测试并出报告；能在 Linux 上用 grep 定位日志中的报错

第 7–9 周阶段三：Python + 自动化入门

目标：能用 Python 写脚本，跑通一个 Web 自动化测试流程

  • 第 7 周：Python 基础 —— 变量、列表/字典、函数、if/for、文件读写、异常处理（只学测试用得到的，不必深入面向对象）
  • 第 8 周：Pytest 框架 —— 断言、fixture、参数化；用 Requests 库做接口自动化（把第 6 周的接口测试用代码实现）
  • 第 9 周：Selenium Web 自动化 —— 元素定位八大方式、显式等待、简单 PO 模式；写一个登录+下单流程的自动化脚本
资源：孙兴华 Python 入门（小白）或廖雪峰教程；B 站「测试开发山哥」Selenium 教程；Pytest 官方文档

✓ 检验：有一个能跑通的接口自动化小项目（Pytest + Requests）和一个 UI 自动化脚本，代码传到 GitHub

第 10–12 周阶段四：项目实战 + 求职准备

目标：形成可写进简历的项目经历，完成面试准备

  • 第 10 周：综合实战 —— 找一个开源电商/管理系统项目，完成完整测试：写测试计划与用例、执行功能测试、Postman 接口测试、SQL 造数与数据校验、提 Bug、写测试报告
  • 第 11 周：性能测试入门 —— JMeter 录制脚本、线程组设置、看 TPS/响应时间/错误率，出一份简单压测报告（面试加分项）
  • 第 12 周：简历打磨 + 面试 —— 牛客网刷软件测试面试题（用例设计题必练）、看面经、模拟自我介绍和项目描述
资源：GitHub 开源项目（搜 testcases / mall 等带文档的项目）；JMeter 官方文档或 B 站 JMeter 教程；牛客网「软件测试」题库

✓ 检验：简历上有 1 个完整测试项目 + 1 个自动化小项目；常见面试题（用例设计、SQL、HTTP、Bug 定位思路）能流畅回答

每日时间安排参考（2.5 小时版）

时段内容时长
第 1 段看课程视频（倍速），跟做笔记60 分钟
第 2 段动手实操当天知识点60 分钟
第 3 段整理笔记 / 遇到的问题写进文档（碎片时间逛 TesterHome、牛客）30 分钟

三个月的红线

  • 不要一上来就学自动化 —— 用例设计和接口测试才是初级岗面试的考察重点
  • 不要囤课囤资料 —— 同一主题跟 1 个博主就够
  • 不要只看不练 —— 每个知识点必须有对应的实操产出
  • 一定要把用例、脚本、报告整理到 GitHub —— 这就是没有工作经验时的"项目经历"
